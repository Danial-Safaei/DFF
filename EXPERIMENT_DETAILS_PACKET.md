D) DFF estimator: CF-XAI method definition, mask/infill details, objective, optimizer, hyperparameters, K_cf averaging, pooling to 16×16, MSE definition, runtime

D.1 DFF similarity and distance
- DFF similarity is cosine similarity between saliency maps; DFF distance is `1 - similarity`. See `compute_dff_similarity` and `compute_dff_distance` in [RQ_corrected.ipynb](RQ_corrected.ipynb#L1069-L1129).

D.2 Counterfactual (CF-XAI) generation
- Counterfactuals are generated by optimizing the input image directly with Adam, using output loss + perturbation + TV loss; always returns best-effort if threshold not met. See `_steering_counterfactual_robust` and `_yolop_counterfactual_robust` in [RQ_corrected.ipynb](RQ_corrected.ipynb#L1139-L1333).
- Mask/infill: no explicit mask or inpainting; perturbation is continuous over the full image tensor with TV regularization (see `_tv_loss` and update loop in the counterfactual functions). [RQ_corrected.ipynb](RQ_corrected.ipynb#L1110-L1195).

D.3 DFF loss definition
- DFF loss is MSE between pooled counterfactual change maps; change maps are pooled to 16×16 via `adaptive_avg_pool2d` and then `MSELoss` is applied. See `compute_dff_loss_cf_steering` and `compute_dff_loss_cf_yolop` in [RQ_corrected.ipynb](RQ_corrected.ipynb#L1335-L1396).

D.4 Hyperparameters and K_cf
- Default CF hyperparameters for DFF loss in training wrapper include `cf_steps=80`, `cf_lr=3e-2` (steering), `cf_lr=2e-2` (YOLOP), `cf_tv=1e-3`. See CLI defaults in [train_k2vk_controlnet_vkitti_seg_dff_steering_COUNTERFACTUAL.py](train_k2vk_controlnet_vkitti_seg_dff_steering_COUNTERFACTUAL.py#L463-L467).
- RQ1/RQ2 evaluation explicitly uses K=80 and downsample=16 for DFF loss. See `CF_STEPS_RQ1 = 80` and `CF_DOWNSAMPLE_RQ1 = 16` in [RQ_corrected.ipynb](RQ_corrected.ipynb#L3007-L3040) and RQ2 CF steps in [RQ_corrected.ipynb](RQ_corrected.ipynb#L3606-L3684).

F) Metrics/thresholds: LPIPS backbone, steering OV formula, IoU computation, eps90/eps95 computation, held-out pass-rates

F.1 IV metric (LPIPS backbone and normalization)
- IV is computed as `1 - LPIPS` (clamped to [0,1]) with LPIPS `net='alex'`, fallback to SSIM and PSNR. See `compute_input_fidelity` in [RQ_corrected.ipynb](RQ_corrected.ipynb#L823-L857).

F.2 Steering OV similarity
- Steering OV similarity uses `exp(-5 * |θ_real - θ_gen|)` with scale 0.2 (so exp(-diff/0.2)). See `compute_ovf_steering_similarity` in [RQ_corrected.ipynb](RQ_corrected.ipynb#L859-L887).

F.3 YOLOP OV similarity (IoU + tolerant metrics for LL)
- DA head uses IoU of binarized masks; LL head uses Chamfer + F1-tolerant hybrid instead of IoU for sparse masks. See `compute_ovf_yolop_similarity` in [RQ_corrected.ipynb](RQ_corrected.ipynb#L944-L988).
